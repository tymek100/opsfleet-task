# Period comparison

Use the same population and definitions for both periods. State exact boundaries and distinguish a complete quarter from a partial period.

Compute change as `current - previous`, and percentage change as `100 * (current - previous) / previous`. When the baseline is zero, report the absolute change and say the percentage is undefined.

For category contributions, retain the sign. If the user asks for the largest changes, rank by absolute change. Combine unlisted categories into Other and check that every contribution sums to the total change.

Revenue, order count and AOV can describe an arithmetic relationship. They do not establish a causal explanation for customer behavior.
