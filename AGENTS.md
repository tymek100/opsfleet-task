# Repository instructions

## Language

- Reply to the user in the language of their message.
- Write and maintain code, identifiers, comments, docstrings, test prompts, user-facing application text, documentation, and Markdown files in English, regardless of the conversation language.
- Test the chatbot in English only.

## Documentation

- Use concise, natural technical English. Retain standard architectural and domain terminology; avoid deliberately simplified language or tutorial-style explanations unless requested.
- State implementation status explicitly and remove repetition without omitting material contracts, constraints, or limitations.
